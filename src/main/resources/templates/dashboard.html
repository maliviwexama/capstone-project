How it works

  1. Submit a maintenance request with your room number, category and a description.
  2. Urgent issues (electrical, plumbing) are handled immediately. Non-urgent requests are processed one residence zone at a time — set by an admin — to prevent system overload.
  3. An admin reviews your request and assigns a technician.
  4. Check "My Requests" anytime to see your request's status and who's assigned to it.
