HOW PRIORITY WORKS

Why does my request have a priority?

The system helps administrators handle the most urgent problems first.

HIGHSafety risks, serious electrical problems, or issues that become more urgent while waiting.
MEDIUMProblems that significantly affect normal residence use but are not an immediate danger.
LOWNon-urgent issues such as minor repairs or convenience problems.

Priority is calculated from the problem category, a reported or detected safety concern and how long the request has been waiting. For example, a report mentioning a broken door and a broken bulb can be flagged as a safety-related report so it is not treated as two ordinary convenience problems.
